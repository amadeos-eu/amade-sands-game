# What each mission gives the two houses, and how the computer plays.
#
#   map       the map in the folder maps, made in Tiled (see the README)
#   credits   the player's credits at the start
#   enemy     the computer's credits at the start
#   worm      yes if a sand worm hunts on the open sand
#   attack    seconds before the computer's first attack
#   every     seconds between its attacks after that
#   army      vehicles in its first attack; each attack after brings grows more
#   grows
#   turrets   how many turrets it builds at most
