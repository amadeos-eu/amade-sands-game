# The buildings of Sands. Change a number, start the game again, play.
#
#   size      width and height in tiles
#   health    hit points; armour as for the units (units.txt)
#   cost      credits, paid while the construction yard builds it; a building without a cost is not built,
#             a map places it
#   seconds   how long that takes at full power
#   power     what a windtrap makes; every other building uses power (a negative number); 0 if not given
#   sight     how far it sees, in tiles
#   storage   credits of spice it stores
#   needs     the buildings its side must have before the yard builds it (none if not given)
#   yard      yes for the construction yard, which builds the buildings
#   factory   yes for the factory, which makes the vehicles
#   radar     yes for the outpost: with enough power, its side sees the minimap
#   dock      the column of the pad a harvester unloads on; a building with a dock comes with a harvester
#   weapon    as for the units: a turret fires on enemies in range

building yard
  size 4 4
  health 1400
  armour 0.3
  sight 6
  storage 1000
  yard yes

building windtrap

  health 400
  armour 0.2
  cost 300

  power 100
